Find the limit of a_n = (3n - n^2) / (n^2 + 4) as n → ∞

Step 1: Identify the dominant terms.
The highest power in numerator and denominator is n^2.
Divide both numerator and denominator by n^2:

  a_n = (3n/n^2 - n^2/n^2) / (n^2/n^2 + 4/n^2)
      = (3/n - 1) / (1 + 4/n^2)

Step 2: As n → ∞, the sub-dominant terms go to 0:
  3/n → 0
  4/n^2 → 0

So the expression simplifies to:
  (0 - 1) / (1 + 0) = -1/1
