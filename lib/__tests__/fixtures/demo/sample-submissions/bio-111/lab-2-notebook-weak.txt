In the lab we used iodine, Benedict's solution, and Biuret reagent to test different substances for macromolecules. Iodine tests for starch and turns dark blue if starch is present. Benedict's solution tests for sugar. Biuret tests for proteins and turns purple.

We tested three substances and got different results for each one. Substance A turned dark blue with iodine, so it has starch in it. Substance B had a positive Benedict's test, so it has sugar. Substance C turned purple with Biuret, so it has protein. We could tell what was in each substance by looking at which tests came back positive. The experiment showed us that different macromolecules react differently to different indicator solutions, which is a way to figure out what is in something without already knowing the answer.
